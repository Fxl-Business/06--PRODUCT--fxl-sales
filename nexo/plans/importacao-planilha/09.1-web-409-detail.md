# Slice 09.1 - surface the 409 row detail on the import screen

## Why

Slice 07 answers a mid-transaction refusal with `409 { error: 'conflict', reason: 'import_execution_failed', message }`, where `message` is `ImportExecutionError.message`: a pt-BR sentence naming the tab and Excel row (for example `Aba Propostas, linha 4: a parcela 1/3 já foi paga.`), with no ids.
Slice 09 (merged) renders a fixed generic sentence for every 409, so the operator cannot tell which row to fix.
`ApiError.body` (added by slice 09 in `apps/web/src/lib/api-client.ts`) already carries the parsed error body.

## Change (only `importErrorMessage` in `import-copy.ts`)

In the `status === 409` branch:

```ts
const body = (error as { body?: unknown }).body;
const detail =
  typeof body === 'object' && body !== null && typeof (body as { message?: unknown }).message === 'string'
    ? (body as { message: string }).message.trim()
    : '';
if (detail) {
  const sentence = /[.!?]$/.test(detail) ? detail : `${detail}.`;
  return `Nada foi importado: ${sentence} Valide a planilha novamente e tente outra vez.`;
}
return '<the existing generic 409 sentence, unchanged>';
```

Update the doc comment above `importErrorMessage` to say: classification keys on the HTTP status only; the 409 branch additionally shows the server's row message when present.

## Red tests first (`__tests__/import-copy.test.ts`, add)

1. `409 with a row message names the row` - an error `{ status: 409, body: { error: 'conflict', reason: 'import_execution_failed', message: 'Aba Propostas, linha 4: a parcela 1/3 já foi paga.' } }` returns exactly `Nada foi importado: Aba Propostas, linha 4: a parcela 1/3 já foi paga. Valide a planilha novamente e tente outra vez.`
2. `409 message without final punctuation gets a period` - message `Aba Leads, linha 2: etapa recusada` returns `Nada foi importado: Aba Leads, linha 2: etapa recusada. Valide a planilha novamente e tente outra vez.`
3. `409 without a message keeps the generic copy` - `{ status: 409 }`, `{ status: 409, body: {} }`, `{ status: 409, body: { message: '   ' } }` and `{ status: 409, body: { message: 42 } }` each return the existing generic 409 sentence.
4. `other statuses ignore body.message` - `{ status: 422, body: { message: 'x' } }` returns the existing 422 sentence.

Build any error object the way the existing tests in that file do (reuse their helper if one exists).
